# PS5 Digital Rentals

Static site mirrored from [fridayfrog.webflow.io](https://fridayfrog.webflow.io) — PlayStation game rental service (digital account rental + physical disc rental).

## Structure

- `site/` — the static site (HTML/CSS/JS/fonts/images), self-contained, no build step
- `site/index.html` — homepage
- `site/game-rentals/` — game library / catalog page

## Run locally

```bash
npx serve site
```
